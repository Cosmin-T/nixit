nixit pacman repository

Install:

curl -fsSL https://cosmin-t.github.io/nixit/install.sh | sudo bash

That's it — adds the repo and installs nixit in one step. After that, updates come through your normal sudo pacman -Syu.

Prefer to edit /etc/pacman.conf yourself?

[nixit]
Server = https://cosmin-t.github.io/nixit/x86_64

Source: github.com/Cosmin-T/nixit
